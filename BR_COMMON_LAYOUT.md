# Что где лежит в common-архиве клиента Black Russia

`common.zip` клиента (раскладка проверена по распаковке) — это конфигурация и данные,
которыми клиент управляет игрой. Что из этого читает наша сборка reVC:

| путь в common | что это | наша поддержка |
|---|---|---|
| `data/timecyc.json` | суточный цикл: 22 погоды × 8 слотов (0,5,7,9,12,17,19,22 ч) с небом/солнцем/туманом/водой/ambient | **читается** (`CCustomTimecycle::Apply`): первые 4 погоды → погоды игры, слоты разворачиваются в 24 часа |
| `data/timecyclePresets/timecyclePreset*.json` | серверные погодные пресеты-события (альтернативные состояния неба) | пишутся в `debug.log`, в цикл не вмешиваются |
| `data/weather.json` | снег клиента (текстура, цвет, исключения) | логируется (в игре снега нет) |
| `anim/ped.ani` | SA IFP v2 — анимации педа | **читается**: `.ani`-записи в zip отдаются загрузчику анимаций (ANP3/ANP2/ANPK) |
| `data/maps/IDE/*.ide` | IDE объектов карты BR | не читается (модели карты приходят в custom-архивах, имена — по IDE при желании можно добавить) |
| `data/*.dat`, `*.ide` (handling, carcols, ped.dat, …) | SA-стиль дата-файлы клиента | не читаются (игра использует свои) |
| `data/texdb.dat`, `data/config.dat` | списки bpc-архивов текстур/мешей клиента (`TEXDB textures/X`, `CDIMAGE mesh\X.bpc`) | справочно: так клиент раскладывает свои модели/текстуры по архивам; наша игра берёт то же самое из zip в `custom` по именам файлов |
| `data/routes/*` | маршруты трафика | не читается |
| `data/features/*.json` | фичи клиента (фейерверки, сцена выбора персонажа и т.п.) | не читается |
| `fonts/*.ttf`, `audio/*` | шрифты и аудио-конфиги клиента | не читается |

## Как это связано с zip-архивами в `custom`

У клиента модели/текстуры/коллизии лежат в собственных контейнерах (`.bpc`) со списками в
`config.dat`/`texdb.dat`. Наша сборка делает то же самое через zip: всё, что лежит в
`custom/**/*.zip` (`.mod`/`.dff`, `.btx`/`.txd`, `.cls`/`.col`, `.ifp`/`.ani`, скины-картинки),
индексируется по именам файлов и грузится в рантайме с приоритетом над файлами игры —
см. `CUSTOM_MODELS.md`. Положить `common.zip` целиком в `custom` тоже можно: из него
подхватятся `data/timecyc.json` (освещение/небо) и `anim/ped.ani`.
