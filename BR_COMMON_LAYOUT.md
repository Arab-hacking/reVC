# Ресурсы `common/` для карты Black Russia

Эта таблица описывает **уже распакованную** папку `common/` в корне игры. Сам архив `common.dec.txt` здесь не нужен: он был использован для анализа состава, но не добавляется в игру или репозиторий. `.bpc` не декодируется и не монтируется. Инструкция по настройке — в [PC_WORLD_MODDING.md](PC_WORLD_MODDING.md#распакованный-common-карта-br).

| Путь в `common/` | Поведение reVC |
|---|---|
| `data/config.dat` | Выбирает активные `IDE`/`IPL`, игнорирует `CDIMAGE`/`TEXDB` на `.bpc` и неиспользуемые записи. В исследованном наборе — 75 IDE и 52 IPL; 85 IPL на диске не означают, что все они активны. |
| `data/maps/**/*.ide` | Из выбранных файлов читаются `objs`, `tobj`, `anim` (без переноса SA-анимации объекта), `peds`, `cars`, `weap`. Текущая версия VC не поддерживает остальные классы транспорта, SA-тип оружия, SA handling или определения эффектов. Новая модель регистрируется только при доступном DFF/MOD из `custom/`, `img/` или штатного IMG. |
| `data/maps/**/*.ipl` | Размещаются только `inst` из выбранных файлов; другие разделы (`occl`, `cull`, `enex` и т. п.) не импортируются. Альтернативные IPL включаются явным `custom/active_ipl.txt`; при наличии списка базовые IPL тоже нужно перечислить. |
| `anim/ped.ani` | Приоритетный `sa_ped`-банк для SA-скелетов, без подмены штатных анимаций VC-скелетов. |
| `data/carcols.dat` | Только палитра RGB секции `col`, если она целиком корректна; VC-назначения цветов по моделям сохраняются. |
| `data/timecyc.json` | Только ambient/directional свет и сила штатных теней. Состояния неба/солнца/тумана/воды и прочие эффекты **не** применяются к распакованному `common/`. |
| `data/timecyclePresets/*`, `data/weather.json` | Не используются при загрузке из распакованного `common/`: нет переноса серверной погоды, снега или дополнительных эффектов. |
| `data/texdb.dat`, `*.bpc` | Не читаются и не монтируются. Самих игровых мешей и текстур в этом `common/` нет: нужны отдельно совместимые DFF/TXD/архивы. |
| `data/handling.cfg`, `data/physics.json`, `data/routes/*`, `data/features/*`, `audio/*`, `AUDO` | Намеренно игнорируются; никакой пользовательской физики машин и аудио. |

Приоритет: другие файлы/архивы в `custom/` → активные IDE/IPL из распакованного `common/` (**позже**, поэтому его одноимённые файлы побеждают). Если одновременно остался `custom/common.zip`, его IDE/IPL при наличии рабочего распакованного манифеста не загружаются вторично; архивные ресурсы моделей и анимаций сохраняются. Совместимые штатные имена повторно используют прежний ID без перезаписи небезопасных VC-полей; неподходящие определения/геометрия пропускаются. TXD с именем DFF может лежать в **другом** пользовательском IMG; коллизии читаются из ZIP в `custom/`, а не из IMG.

Отражения сцены Neo и UV2/DUAL-lightmaps доступны условно; графические `.btx` можно взять из **отдельных ZIP в корневой `zip/`** (параметры выбора и важные ограничения — в [PC_GRAPHICS_ZIP.md](PC_GRAPHICS_ZIP.md)). Это **не** параболический envmap-проход BR, и визуальное совпадение не установлено. Тени — встроенные VC, **не** depth-map/PCF из архитектурного отчёта. Кэши `.mod`/`.btx` не расширяются. Игровое поведение на полном наборе ресурсов пока не проверено.

Если распакованного `common/` нет, для старого `custom/common.zip` действует прежний механизм архивов: его IDE/IPL загружаются по старым правилам. Ограничение только освещением и тенями относится **именно к распакованному `common/`**. Не используйте ZIP вместо папки, если хотите отбор по `config.dat` и этот приоритет.
