# Android APK reVC

Сборка Android теперь подключает **настоящий игровой модуль** из корня reVC:
`android/launcher/app/CMakeLists.txt` собирает `librevc.so` и упаковывает его
в APK вместе с SDL2, mpg123 и OpenAL для `armeabi-v7a` и `arm64-v8a`.
Стартовый экран больше не является заглушкой: он подготавливает дополнительные
файлы reVC, импортирует ваши файлы GTA Vice City и запускает SDL-игру.

## Получить APK

В [Android Actions этого репозитория](https://github.com/Arab-hacking/reVC/actions/workflows/build-android.yml)
выберите **успешный запуск для своей ветки/PR** и скачайте артефакт
`revc-release` (внутри `app-release.apk`). Для диагностики есть `revc-debug`.
Release-вариант больше **не подписывается отладочным ключом**. Если ключ не
задан, CI собирает неподписанный `app-release-unsigned.apk` — подпишите его
`apksigner` перед установкой или задайте собственный keystore:

```bash
export REVC_KEYSTORE=/path/to/revc.jks
export REVC_KEYSTORE_PASSWORD=...
export REVC_KEY_ALIAS=revc
export REVC_KEY_PASSWORD=...
./gradlew assembleRelease
```

Те же значения можно передать через `-PrevcKeystore=...`,
`-PrevcKeystorePassword=...`, `-PrevcKeyAlias=...`, `-PrevcKeyPassword=...`.
Установка на Android 7.0+ может потребовать разрешения устанавливать APK из
выбранного источника.

Сборка из исходников: откройте `android/launcher` в Android Studio с JDK 17,
SDK 35, NDK `27.2.12479018` и CMake `3.22.1`. Клонируйте репозиторий с
подмодулями, затем выполните `./gradlew assembleDebug` или
`./gradlew assembleRelease` из `android/launcher`. CI после сборки проверяет
обе архитектуры, `SDL_main`, нативные зависимости и файлы поддержки внутри APK.

Хостовые тесты (без NDK, только `g++` и `python3`):

```bash
python3 tests/GL3ShaderTests.py          # GLSL/inc-паритет шейдеров GL3
cmake -S tests -B build-tests && cmake --build build-tests -j
ctest --test-dir build-tests --output-on-failure
```

## История исправлений в этой ветке

Отдельно стоит знать, что изменилось в поведении:

- **GL-контекст.** Версия GL читается у драйвера до загрузки точек входа
  (`glad`), поэтому контекст ES 3.0 больше не превращается в ошибку
  загрузчика. Контекст ES 2.0 отклоняется с понятным сообщением: шейдеры
  рендерера — ES 3.00.
- **Тени среднего качества** переиспользуют карту только пока не изменились
  игровое время и погода, иначе тени «отрывались» от объектов.
- **Тап по экранным кнопкам** длиной в один кадр больше не теряется: нажатие
  удерживается пару кадров `UpdatePad()`.
- **Звук.** Если устройство не даёт аудио-устройство (эмулятор, занятый
  маршрут), игра запускается без звука вместо падения.
- **Коллизия из `custom/`.** Порядок полей `TBounds` в COL2/COL3 определяется
  по данным, а не по платформе, поэтому один и тот же `.col`/`.cls`
  конвертируется одинаково на Android и на ПК.
- **Кнопки разработчика** (спавнер скина/машины, полёт, время) не попадают в
  `MASTER`-сборку.

## Подготовить игру на телефоне

**APK не содержит GTA Vice City.** Требуется своя копия **PC-версии** игры.
Перенесите *полную* папку игры на телефон; в её корне должны быть как минимум
`data/gta_vc.dat`, `models/gta3.img`, а также остальные папки (`audio`, `anim`,
`txd` и т. д.). Не выбирайте папку, которая содержит папку игры ещё на один
уровень ниже.

1. Установите APK и откройте reVC.
2. Нажмите «Выбрать и импортировать папку игры», укажите папку своей копии
   Vice City в системном диалоге Android и дождитесь окончания копирования.
3. Когда появится «Можно запускать», нажмите «Запустить игру».

Импорт идёт в **закрытую для других приложений папку** reVC
(`/sdcard/Android/data/com.revc.game/files/` или внутренний аналог); системный
выбор папки позволяет читать исходные файлы без разрешения полного доступа к
хранилищу. Перед импортом проверьте свободное место: на устройстве будут
храниться и исходная копия, и импортированная. При удалении приложения
Android может удалить импортированные файлы. Дополнительные файлы движка из
`gamefiles/` копируются приложением автоматически.

## Что проверено, а что нет

Android CI собирает Debug/Release APK и проверяет **наличие настоящей игры и
динамических библиотек**, но не может проверить геймплей на телефоне без
пользовательских игровых файлов. Отсутствие ошибки компиляции не доказывает
совместимости со всеми устройствами и наборами ресурсов. Если игра вылетит,
пришлите модель/версию Android, версию APK, `debug.log` из папки reVC и вывод
`adb logcat` вокруг вылета; этим можно проверить, на каком этапе он происходит.
